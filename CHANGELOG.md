# Changelog

## 0.1.1 — 2026-11-09

- Added sign-in, Kanban, filter overlay, planner, and document screenshots.
- Included a loopback-only, read-only dummy-data preview server in the release ZIP.
- Added the screenshot gallery and preview instructions to the README.

## 0.1.0 — 2026-11-09

- First standalone open-source release of IITEG Workspace under MIT.
- Glass-style light/dark interface; boards, subtasks, custom columns, planner,
  chat, shared docs, teams, permissions, presence and time tracking.
- Clean PHP API, environment-only configuration, CLI installation, Docker Compose,
  and optional fictional demo content.
- Trusted manifest/React-panel extension registry for custom subsidiaries.
- No company business modules, production integrations, private data, commercial
  fonts or inherited repository history.
- Portal-based Kanban filter menu above frosted board layers.
