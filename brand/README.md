# Workspace identity

Blue glass W inside a rounded glass frame, with alpha transparency outside the frame. No text is included in the logo.

- `workspace-icon-master.png`: approved transparent artwork.
- `workspace-icon-{16,32,48,180,192,512,1024}.png`: browser, app, and documentation exports.
- `workspace-logo-preview.png`: full-size preview.
- Legacy SVG and wordmark filenames embed the same W-and-frame artwork for compatibility; these are raster artwork, not vector or monochrome masters.
