# Architecture

The public distribution is a browser SPA. File-based routes are generated by
TanStack Router; `src/main.tsx` mounts it. No SSR or vendor-specific platform is
required. Vite writes the static build into `dist/client/`.

`src/lib/api.ts` is the HTTP and bearer-session boundary. It defaults to the
same-origin `/api` proxy; it never connects to a production company backend.
The workspace client normalizes database IDs and tracks request status.

`backend/auth.php` handles sign-in. `backend/admin/workspace.php` routes the
core resources. `permissions.php` defines ranks, permissions, and ACL checks;
`scope.php` checks object visibility; `backend/lib/workspace.php` contains schema
helpers. `backend/bin/setup.php` runs only from CLI and creates the owner on an
empty installation. Optional seeding is a separate, fictional dataset.

There is no public registration or password recovery mailer in 0.1.0. Owners
create accounts from Invite. Sessions expire after 12 hours; password changes
and deleting an account invalidate its existing sessions. Logout clears the
local browser token. See SECURITY.md for attachment and extension boundaries.

The core ships no company business modules. New bundled subsidiary panels use
`src/extensions/manifest.json` and `src/extensions/index.ts`.
